# LoomAI Backend API Documentation

This document outlines the REST API endpoints available in the LoomAI Textile Marketplace backend.
All endpoints are prefixed with `/api/v1`.
All responses follow the standard `ApiResponse` envelope:
```json
{
  "success": true,
  "message": "Human readable message",
  "data": { ... },
  "meta": { ... } // Optional pagination
}
```

---

## 1. Authentication (`/auth`)

### `POST /auth/buyer/register`
Register a new Buyer account.
- **Body**: `{ name, email, password, contactName, phone }`
- **Response**: `201 Created` with JWT `accessToken`.

### `POST /auth/buyer/login`
Authenticate a Buyer.
- **Body**: `{ email, password }`
- **Response**: `200 OK` with JWT `accessToken`.

### `POST /auth/supplier/register`
Register a new Supplier account.
- **Body**: `{ name, email, password, contactName, location, gst, phone }`
- **Response**: `201 Created` with JWT `accessToken`.

### `POST /auth/supplier/login`
Authenticate a Supplier.
- **Body**: `{ email, password }`
- **Response**: `200 OK` with JWT `accessToken`.

---

## 2. Public Marketplace Data (`/categories`, `/knowledge`, `/products`)

### `GET /categories`
Retrieve all marketplace categories and taxonomies.
- **Response**: `200 OK` (Array of Category objects)

### `GET /knowledge`
Retrieve or search textile knowledge base articles.
- **Query Params**: `q` (search term), `category`, `difficulty`, `tags`, `sort`, `page`, `limit`
- **Response**: `200 OK` (Paginated list of Articles)

---

## 3. Buyer Endpoints (`/buyer`)
*Requires: `Authorization: Bearer <token>` (Role: Buyer)*

### `GET /buyer/profile`
Retrieve the authenticated buyer's profile.
- **Response**: `200 OK`

### `GET /buyer/orders`
Retrieve procurement order history for the buyer.
- **Response**: `200 OK` (Array of Order objects)

### `POST /buyer/orders`
Create a new procurement order (simulated checkout).
- **Body**: `{ items: [{ productId, quantity }], totalAmount, shippingAddress }`
- **Response**: `201 Created`

---

## 4. Supplier Endpoints (`/supplier`)
*Requires: `Authorization: Bearer <token>` (Role: Supplier)*

### `GET /supplier/profile`
Retrieve the authenticated supplier's business profile.
- **Response**: `200 OK`

### `GET /supplier/dashboard`
Retrieve aggregated dashboard metrics for the supplier (active products, pending orders, revenue).
- **Response**: `200 OK`

### `GET /supplier/products`
Retrieve inventory for the authenticated supplier.
- **Query Params**: `page`, `limit`
- **Response**: `200 OK` (Paginated Products)

### `GET /supplier/orders`
Retrieve incoming sales orders for the supplier.
- **Response**: `200 OK`

### `PATCH /supplier/orders/:id/status`
Update the fulfillment status of an order.
- **Body**: `{ status: 'Preparing' | 'Dispatch' | 'Delivered' }`
- **Response**: `200 OK`

---

## 5. AI & Multi-Agent Intelligence (`/ai`)

### `POST /ai/chat`
Stream a unified chat interaction using the LangGraph Supervisor.
- **Body**: `{ message: string, sessionId: string, context?: object }`
- **Response**: `200 OK` (Server-Sent Events / Stream) yielding `data: { content, nextAgent }`

### `GET /ai/analytics/summary`
Retrieve platform-wide summary metrics generated by AI analytics.
- **Response**: `200 OK`

### `GET /ai/advisor/report`
Generate a strategic business intelligence report using the BusinessAdvisor workflow.
- **Requires**: `Authorization: Bearer <token>`
- **Response**: `200 OK` (Markdown report)
